# Code of Conduct

## Our pledge

We want KatMusic to be a welcoming project for everyone, regardless of experience
level, background, identity or language.

## Expected behaviour

- Be respectful and assume good faith.
- Give constructive feedback about code, not people.
- Keep discussions on topic; move long side conversations elsewhere.
- Credit other people's work and ideas.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing someone's private information without permission.
- Posting credentials, API keys, cookies or other secrets.
- Deliberately derailing issues or pull requests.

## Enforcement

Maintainers may edit or remove comments, close issues and block accounts that violate
this document. Report problems to the maintainer via a private channel through the [Arct Development GitHub organization](https://github.com/Arct-Development). Reports are handled discreetly.
