    Ask on GitHub
    Which platforms does KatMusic run on?+

    Android 10 and newer (with a legacy package for Android 7–9), plus Windows 10/11, macOS 12+ and 64-bit Linux. Every build is published on the same GitHub release.

    Which file should I download?+

    Use the platform tabs in the download section. On Android, the universal APK is the safe default, ARM64 is smaller for 64-bit phones, and the legacy package is only for Android 7–9.

    Is KatMusic an official YouTube Music app?+

    No. KatMusic is an independent, third-party project. It is not affiliated with, endorsed by or officially connected to Google or YouTube.

    How do shared track links work?+

    Sharing a track copies a katmusic.pages.dev link. When someone opens it, the page shows the track and asks the system to open it in KatMusic; if the app is not installed, the page stays usable with a YouTube Music fallback.

    Which Android versions are supported?+

    The current release offers Android 10+ packages and a legacy package for Android 7–9. Some features and media controls use alternatives on older Android versions.

    How does Listen Together work?+

    Create a room and invite friends with its code. The host approves who joins, and rooms include chat and synchronized playback. You can also join a room someone shared with you.

    What is Group Blend?+

    Group Blend is a taste match built from your KatMusic listening history. You can create a Blend, or join a friend's with an invitation code. No Spotify account is needed.

    Do I need an account?+

    You can log in with YouTube Music or continue as a guest. Guest mode works fully offline with local recommendations, and you can connect Last.fm in Settings to sync scrobbles.

    Does every audio feature work on every device?+

    No. Output modes, supported codecs and bit-perfect behaviour depend on the device, DAC, audio route and operating-system limits. The desktop builds use the host's audio stack.

    Does KatMusic collect analytics?+

    The project README states that KatMusic does not bundle an analytics or advertising-tracking SDK. Network requests are made to services required by the features you use.

    Can I inspect or contribute to the source?+

    Yes. KatMusic is GPL-3.0 licensed. The source, issue tracker, contribution guide and release history are public on GitHub.
